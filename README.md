# Private Skills

Client-specific agent skills, and skills whose examples come from client work. Keep this repository private.

| Skill | Use it to |
| --- | --- |
| `pmt-tatanan-lead-review` | Review a Tatanan PR. It extends `lead-review` from [tech-lead-skills](https://github.com/snowfluke/tech-lead-skills). |
| `app-launch-video` | Build a 90 s to 3 min launch video for an app you have the source of. Needs the HyperFrames skills: `npx skills add heygen-com/hyperframes -g`. |
| `motion-reel` | Build a 15 to 45 s looping motion-graphics reel. Reads `app-launch-video`'s brand guide. |

Link the skills into your skills directory with `./link.sh` (default: `~/.claude/skills`).
